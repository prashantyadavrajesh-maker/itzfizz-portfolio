# 🚀 ITZFIZZ - Modern Web Experience

A modern and interactive portfolio website built with React, GSAP animations, and responsive UI design.

This project focuses on smooth scrolling, creative animations, and a clean developer-focused user experience.

# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/yourusername/itzfizz.git
```

Go to project folder:

```bash
cd itzfizz
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
